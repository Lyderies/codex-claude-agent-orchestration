# Plan change

Trace each planned outcome to an accepted requirement or decision. Identify dependencies
and order work by what must be learned or proved first. Separate parallel read work from
write work that can conflict. Give every step an observable exit condition and relevant
validation. Record material alternatives as open decisions rather than choosing them
silently. Do not claim implementation or verification that has not occurred.
